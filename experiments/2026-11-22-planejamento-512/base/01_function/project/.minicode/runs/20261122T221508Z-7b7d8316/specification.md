### Objetivo
O objetivo é criar uma função `sum_even` que recebe uma lista de números e retorna a soma de todos os números pares presentes nessa lista.

### Restrições explícitas
- A função deve receber um único parâmetro: uma lista de números (`numbers`).
- A função deve retornar um número inteiro que seja a soma dos números pares da lista.
- Os números ímpares devem ser ignorados.

### Critérios de aceitação verificáveis
- Dada a lista `[1, 2, 3, 4]`, a função deve retornar `6`.
- Dada a lista `[0, 1, 2, 3, 4, 5]`, a função deve retornar `6`.
- Dada a lista `[10, 21, 32, 43, 54]`, a função deve retornar `96`.
