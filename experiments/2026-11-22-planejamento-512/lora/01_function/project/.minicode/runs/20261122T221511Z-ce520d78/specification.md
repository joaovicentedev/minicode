### Objetivo
A função `sum_even` deve receber uma lista de números e retornar a soma de todos os números pares contidos nessa lista.

### Restrições Explícitas
- A função deve ser chamada `sum_even`.
- A função deve aceitar uma única argumento, que é uma lista de números.
- A função deve retornar um número inteiro que representa a soma dos números pares na lista fornecida.

### Critérios de Aceitação Verificáveis
- Dada a lista `[1, 2, 3, 4]`, a função deve retornar `6`.
- Dada a lista `[0, 1, 3, 5]`, a função deve retornar `0`.
- Dada a lista `[8, -2, 7, 0]`, a função deve retornar `6`.
