### Objetivo
Implementar a função `sum_even` que recebe uma lista de números e retorna a soma de todos os números pares presentes nessa lista.

### Restrições explícitas
- A função deve receber um parâmetro chamado `numbers`, que é uma lista.
- O retorno da função deve ser um número inteiro.

### Critérios de aceitação verificáveis
- Dada a lista `[1, 2, 3, 4]`, a função deve retornar `6`.
- Dada a lista `[0, 1, 2, 3, 4, 5, 6]`, a função deve retornar `12`.
- Dada a lista `[7, 8, 9, 10]`, a função deve retornar `18`.
